# 開發工具（不需修改）

這個資料夾是開發與建置用的工具程式，遊戲本身不會用到，平常維護遊戲**不需要修改這裡**。

| 資料夾      | 用途                                                                                                 | 怎麼執行                |
| ----------- | ---------------------------------------------------------------------------------------------------- | ----------------------- |
| `素材轉檔/` | `遊戲素材/` → `public/`（webp、mp3、素材清單）；圖集、點陣字切圖 → `src/data/atlas`、`src/data/font` | `npm run assets`        |
| `手機檢查/` | 手機操作自動檢查                                                                                     | `npm run check:mobile`  |
| `部署/`     | develop 版素材與正式版共用（GitHub Pages）                                                           | 見 `docs/分支與發布.md` |
| `復刻分析/` | 原版錄影逐禎截圖、場景索引、接觸表、並排比對、找素材                                                 | 見 `docs/復刻分析/`     |
