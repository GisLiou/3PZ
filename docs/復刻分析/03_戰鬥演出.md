# 03 戰鬥版面與一回合演出（v1 修復展示 720P，114 000～127 000 ms）

v1 是 30 fps（每禎 33.3 ms）、720×1278，比教學錄影（v5，18.69 fps、360 寬）清楚，演出細節以 v1 為準。
原解析度逐禎截圖：`game/_開發工具_不需修改/復刻分析/hires.sh 參考資料/三国志puzzle大战修复展示_720P.mp4 114000 127000 <資料夾>`（檔名＝毫秒）。
實作：`game/src/modules/battle/`（`components/`：畫面組合 `StandardBattleLayout.tsx`、`BattleCanvas.tsx`；`logic/`：`BattleScreen.ts`、`units.ts`、`effects.ts`、`BoardView.ts`）；敵人站位與大小依星數自動計算（`formation.ts` 的 `arrangeRows`、`arrangeEnemies`、`scaleOfStars`）；時間常數寫在各檔內（`turnTiming`、`unitTiming`、`effectTiming`、`boardTiming`）。

## 6. 尚未完全一致

1. 魂柱與魂團的粉紅色：原圖 `ef_souldrop00` 是白色，用 CSS 濾鏡上色（自製素材 README #10）；原版可能用的是其他素材或引擎上色。
2. 金幣掉落、敵人死亡的黑色爆炸素材尚未找到。
3. 命中時的畫面閃白尚未加入；各兵種攻擊特效的角度與大小為依 v5 低解析畫面的推測。

5. 兵種必殺技演出（v3、v6～v8）尚未分析。

## 兵種攻擊動作（素材拼湊）

- 小兵動作取自 `UI等/戰鬥效果/attack<勢力><兵種>`（背面，4～6 張；部分零件轉 90° 存放，顯示時轉回）。每個兵種分 run（跑步／頭上跳動）與 attack（攻擊）兩組，零件與角度記在 `data/troops.json`；各勢力圖集的零件順序不同，以魏的零件為基準用圖形比對對應。
- 近戰（衝到敵人腳下）：劍兵 跳起舉劍 → 揮下＋`zangeki_ef` 斜斬；槍兵 舉槍 → 前撲突刺＋`spear_ef_00/01`；蠻兵 舉斧 → 躍起 → 劈下＋`axe_ef`；騎兵 馬匹奔馳 → 人立衝擊＋`trooper_ef`。命中前一禎全黑（v5 159 711）。
- 遠程（留在頭像上方）：弓兵 取箭 → 拉弓 → 放箭（`ya` 三連射，命中 `arrow_ef_00/01`）；神算 揮羽扇 → 火球 `shinsan_ef` 飛向敵人，命中處 `fire_01～10` 逐張燃燒；鬼謀 舉竹簡 → 頭上竹簡 `chikukan00～03` 攤開（和、平）→ 召喚兩名伏兵（`kibou001` 零件 6、11，各勢力相同）從左右跳向敵人斬擊，紫色墨花（零件 0）。
- `戰鬥效果/arrow、axe、kibou、sinsan、spear、sword、trooper<勢力><張>` 為各兵種的大型動畫素材（側面角色、雷、火等），目前只用了鬼謀的伏兵與墨花；其餘疑為特技／軍略演出，尚未使用。

## 前往下一個合戰（v5 166 000～172 300）

- 打倒一個合戰的敵人後，路面紋理持續往畫面下方推進（部隊往前走），盤面上的小兵原地踏步；之後才出現「合戰 n/m」。
- 實作：`BattleScreen.playAdvance`（`turnTiming.advanceMs` 1.5 秒；原版約 6 秒，期間有玲玲對話）＝`BattleBackground.playAdvance`（地面每禎重畫，貼圖列位移）＋`BoardView.setMarching`。
- 小兵走路（開場進場、補位、踏步）跨步時抬起 `boardTiming.walkBob`；開場進場放慢到 750 ms（原版整片滑入 374 ms）。
