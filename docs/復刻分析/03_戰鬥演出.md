# 03 戰鬥版面與一回合演出（v1 修復展示 720P，114 000～127 000 ms）

v1 是 30 fps（每禎 33.3 ms）、720×1278，比教學錄影（v5，18.69 fps、360 寬）清楚，演出細節以 v1 為準。
原解析度逐禎截圖：`game/tools/replica/hires.sh 參考資料/三国志puzzle大战修复展示_720P.mp4 114000 127000 <資料夾>`（檔名＝毫秒）。
實作：`game/src/modules/battle/screen/`（`BattleScreen.ts` 與各子部分）、`battle/boardView/BoardView.ts`；時間常數 `game/src/modules/battle/timing/battleTiming.ts`。

## 1. 版面（四個區塊）

| 區塊 | 內容 | 位置（設計單位，底部 999 為基準） |
|---|---|---|
| 敵方區 | 天空、地面、敵人、殘數、敵人 HP | 螢幕頂端～y405；**螢幕較高時往上延伸**（天空拉長），不再留空白 |
| 我方區 | 頭像（6 格位，100×100，x10+105n）、HP 條、回復數字 | y405～545 |

| 效果層 | 小兵、魂、傷害數字、命中特效 | 蓋在以上三區之上，可跨區移動 |

寶箱與 Menu 固定在螢幕最上方。其餘畫面（選單等）仍放在置中的 1136 高版面內。

## 4. 連擊倍率（121 900～123 400）

- 盤面變暗。有傷害的武將頭上小兵上下跳：267 ms 一上一下，跳起時雙手張開（零件 p94）。
- 每 533 ms 亮一下（121 900、122 433、122 967）。
- 數字在小兵腳下從原值往上數到 ×(1＋(連擊數－1)×0.25)，約 1 500 ms。

## 6. 尚未完全一致

1. 魂柱與魂團的粉紅色：原圖 `ef_souldrop00` 是白色，用 CSS 濾鏡上色（自製素材 README #10）；原版可能用的是其他素材或引擎上色。
2. 金幣掉落、敵人死亡的黑色爆炸素材尚未找到。
3. 命中時原版的光線（attackeffect1 直線光）與畫面閃白尚未加入。
4. 敵方地面仍是平面梯形（自製素材 README #8）。
5. 兵種必殺技演出（v3、v6～v8）尚未分析。

## 8. 素材確認（戰鬥效果／戰鬥特效）

- `attackNM`（N 勢力 0 魏 1 吳 2 蜀 3 漢 4 群；M 兵種 0 騎兵 1 弓兵? 2 槍兵 3 劍兵 4 ? 5 軍師 6 斧兵）：衝鋒用的大隻小兵圖集，每個零件為一張姿勢。
- `effect_data`：紅色斬線、白色放射光、血花、彩色魂球（37 個零件，`src/data/atlas/effect_data.json`）。
- 兵種與武將的對應資料尚未取得；目前紅／紫／綠／魏用槍兵、群雄用騎兵（與影片一致）。
