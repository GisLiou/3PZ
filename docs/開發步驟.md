### 已知與原版不同、或尚未找到素材的地方

- 標題圖用的是日版 `title.png`，台灣版中文 logo 未找到（`素材說明.md` §4）。
- 標題列底板暫用藍色 `caption_02.png`，原版為深綠（待圖集切圖後替換）。
- 開發商／發行商標誌畫面沒有做（`復刻分析/01_開場流程.md`）。
- 戰鬥中玲玲的表情零件合成位置未解出，目前只有一種表情（`復刻分析/02_教學戰鬥1.md`）。
- 敵人頭上「殘」字、魂的粉紅色、死亡爆炸與煙霧、敵人攻擊泛紅等，暫以程式或濾鏡代替（`自製素材/README.md`）。
- 敵人死亡的金幣、過關報酬畫面未做（過關後顯示「尚在復刻中」）。
- 盤面格線 `pazzle_grid` 在教學戰鬥開場時隱藏，玲玲出現時才顯示；原版格線出現的確切時間未確認（`復刻分析/02_教學戰鬥1.md` §6.2）。
- 故事畫面的白線、光芒大小以目測量測，與原版約有一禎誤差。
- 敵人攻擊時「整個畫面晃動」的 CSS 不會生效（`.battle-screen .is-shaking` 只對子元素有效），是否要晃動待對照錄影。
