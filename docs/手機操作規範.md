# 手機操作規範（每個畫面都要符合）

| # | 規範 | 實作 | 自動檢查（`npm run check:mobile`） |
|---|---|---|---|
| 1 | 返回鍵＝遊戲內返回，不可讓瀏覽器回上一頁或離開 | `core/navigation/backButton.ts`：歷史陷阱 + Android 返回鍵 + Esc，全部導到 `sceneRouter.back()` | ✓ 按瀏覽器返回後仍在遊戲內 |
| 2 | 捲動用手指拖曳（含慣性、回彈），不用點擊式捲動、不用原生捲軸 | `core/input/DragScroll.tsx` | ✓ 舞台內不可有 `overflow:auto/scroll` |
| 3 | 拖動清單時不可誤觸按鈕 | DragScroll 拖動超過 8px 後吃掉該次點擊 | 人工 |
| 4 | 按鈕在「放開時、手指仍在按鈕上」才觸發，按下時換成 `_dark` 素材 | `ui/components/SpriteButton.tsx`（pointer 事件，無 300ms 延遲） | 人工 |
| 5 | 禁止雙指縮放、雙擊縮放、長按選單、文字選取、整頁拖動 | `index.html` viewport、`touch-action:none`、`main.tsx` | ✓ viewport 與 touch-action |
| 6 | 聲音在第一次觸碰後才播放（手機瀏覽器限制） | `audioService.unlock()` | 人工 |
| 7 | 輸入框可正常叫出鍵盤、可選取文字 | 輸入框單獨設 `user-select:text` | 人工 |
| 8 | 螢幕比例不同時不變形：固定 640 寬、高度 960～1136 | `core/stage/stage.ts` | 人工 |
| 9 | 不可有 JS 錯誤、不可缺圖 | 素材 id 不存在時直接丟錯 | ✓ |
