# 關卡格式

新增關卡＝在 `game/src/data/stages/` 新增一個 JSON，不用寫程式。開發版網址 `#scene=battle&stage=<檔名>` 可直接開。
讀取與檢查在 `game/src/modules/battle/logic/stageData.ts`；格式寫錯時（敵人 id 打錯、勝利條件的對象不在合戰裡…）畫面會直接報錯，訊息會指出是哪一關、哪個合戰。

## 1. 檔案

| 檔案                      | 內容                                       |
| ------------------------- | ------------------------------------------ |
| `data/stages/<關卡>.json` | 一個關卡：部隊、合戰、敵人、勝利條件、教學 |
| `data/enemies.json`       | **敵人資料庫**（各關卡共用）：key＝敵人 id |
| `data/parties.json`       | **我方部隊**（各關卡共用）：key＝部隊 id   |

## 2. 關卡

```json
{
  "name": "測試用無限關卡",
  "bgm": "bg_00002",
  "party": "tutorial",
  "leaderSkill": { "faction": "starter", "multiplier": 1.5 },
  "board": { "refill": "random" },
  "waves": [
    { "enemies": ["yellowTurbanSpearman", "caoSwordsman", "hanSwordsman"] },
    {
      "enemies": ["caoSwordsman", "zhouYu", "sunArcher"],
      "victory": { "type": "defeat", "targets": ["zhouYu"] }
    },
    { "enemies": ["luBu"], "bgm": "bg_00003" }
  ]
}
```

| 欄位           | 必填 | 說明                                                                              |
| -------------- | ---- | --------------------------------------------------------------------------------- |
| `name`         | ✓    | 關卡名稱                                                                          |
| `bgm`          | ✓    | 背景音樂（`遊戲素材/BGM` 的檔名）                                                 |
| `party`        | ✓    | 我方部隊：`data/parties.json` 的 id，或直接寫陣列（格式同 parties.json）          |
| `leaderSkill`  |      | 軍略：`faction` 的武將攻擊力變為 `multiplier` 倍（`"starter"`＝玩家選的主角勢力） |
| `board.refill` | ✓    | 補位的新小兵：`"random"` 隨機、`"peach"` 都是桃子（教學用）                       |
| `waves`        | ✓    | 合戰清單。**合戰數＝這裡的個數**（「合戰 n/總數」的總數），1 個、5 個都可以       |
| `enemies`      |      | 這關專用的敵人（格式同 enemies.json；同 id 時蓋過資料庫）                         |
| `endless`      |      | `true`＝最後一個合戰打完從第一個再來（測試用）；Menu 多一個「跳過這個合戰」       |
| `tutorial`     |      | 教學：`script`（步驟）、`moves`（錄影盤面）、`starterLetter`；有寫就照步驟執行    |
| `base`         |      | 繼承另一個關卡，只寫不同的欄位                                                    |

### 2.1 合戰（`waves` 的一項）

| 欄位      | 說明                                                                                                      |
| --------- | --------------------------------------------------------------------------------------------------------- |
| `enemies` | 敵人 id 清單，順序＝由左到右。也可以寫 `{ "id": "zhouYu", "hp": 200, "skills": [] }` 只覆寫這個合戰的欄位 |
| `victory` | 勝利條件（見 2.2）；沒寫＝打倒全部敵人，不顯示提示                                                        |
| `bgm`     | 從這個合戰開始換背景音樂                                                                                  |

### 2.2 勝利條件（每個合戰各自設定）

| `type`              | 參數                    | 過關條件                                        | 自動提示                   |
| ------------------- | ----------------------- | ----------------------------------------------- | -------------------------- |
| （不寫）`defeatAll` |                         | 打倒全部敵人                                    | 不顯示                     |
| `defeat`            | `targets`：敵人 id 陣列 | 打倒指定的敵人（同 id 有多個要全部打倒）        | 打倒〇〇                   |
| `survive`           | `turns`                 | 撐過 N 個敵人回合                               | 撐過 N 回合（還剩 n 回合） |
| `combo`             | `count`                 | 一回合達成 N 連擊                               | 一回合達成 N 連擊          |
| `damage`            | `amount`                | 一回合造成 N 以上的傷害（全體攻擊每個敵人都算） | 一回合造成 N 以上的傷害    |

- 每種都可以加 `"hint": "文字"` 取代自動提示（`\n` 換行）。
- 不論哪種條件，敵人全倒一律算過關。條件達成但還有敵人時，剩下的敵人退場，再前往下一個合戰。
- 提示顯示在相剋圖下方：`StandardBattleLayout.tsx` 的 `<VictoryHint anchor="top" x y w size />`（改了存檔即熱更新；外框樣式在 `battle.css` 的 `.victory-hint`）。

## 3. 敵人（`data/enemies.json`）

```json
"luBu": {
  "name": "呂布", "showName": true,
  "art": "武將圖鑑立繪/5.群/ch_54100189_ll【強弓徹甲】呂布",
  "faction": "qun", "stars": 5, "hp": 2500,
  "attack": { "damage": 50, "interval": 2, "voice": "武將圖鑑語音/5.群/呂布/CV小山　剛志/54100189_vcc_01" },
  "skills": [
    { "name": "天下無雙", "when": { "every": 3 }, "damage": 120, "fx": "thunder",
      "boardEffect": { "type": "convert", "to": "qun", "count": 6 } }
  ]
}
```

| 欄位               | 說明                                                                             |
| ------------------ | -------------------------------------------------------------------------------- |
| `name`、`showName` | 名稱；`showName: true` 在腳下顯示名牌                                            |
| `art`              | 立繪素材 id                                                                      |
| `faction`          | 勢力（`wei` `wu` `shu` `han` `qun`）                                             |
| `stars`            | 星數：**越高立繪越大**（見 4 的「大小」），也決定站位（見 4）                    |
| `hp`               | HP                                                                               |
| `attack`           | 普攻：`damage`、`interval`（每幾回合攻擊一次＝頭上「殘 N」）＋攻擊內容（見下表） |
| `skills`           | 技能（可多個）：`name`（攻擊時顯示在敵人頭上）、`when`（使用條件）＋攻擊內容     |
| `firstCountdown`   | 合戰開始時的「殘 N」（省略＝`interval`）。例：`interval: 1`、`firstCountdown: 2` |
| `firstStrike`      | 先攻：`"attack"`（普攻）或技能的 `name`。開場「殘 1」，第一個敵人回合就用這招    |

**攻擊內容**（普攻、技能都可以寫）：

| 欄位          | 說明                                                                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `damage`      | 對我方的傷害（0＝不攻擊，例：只回血、只改盤面的技能）                                                                                                   |
| `fx`          | 特效：`blood`（預設，敵人身上濺血）、`fire`（火焰打到我方）、`thunder`（雷擊）、`none`                                                                  |
| `voice`       | 攻擊時的語音 id（`武將圖鑑語音/…` 不含副檔名；沒下載語音包時略過）                                                                                      |
| `boardEffect` | 結束後對盤面的效果：`{ "type": "convert", "to": "wu", "count": 4, "from": ["peach"] }`＝隨機 `count` 個小兵（`from` 種類之一，省略＝任何種類）換成 `to` |
| `healSelf`    | 回復自己最大 HP 的比例（0.2＝20%）                                                                                                                      |

**「殘 N」怎麼數**：每個敵人回合減 1，最少是 0。變成 0 的敵人當下攻擊，我方 HP 開始減少的同時回到 `interval`（沒有傷害的招式：在效果開始時）。數字平常是白色，只剩 1（下個敵人回合就攻擊）時變紅色並忽暗忽明。

```json
"zuoCi": { "attack": { "damage": 20, "interval": 2 }, "firstStrike": "attack" }
```

→ 開場「殘 1」→ 我方轉珠後變 0 並普攻 → 我方 HP 減少的同時變回「殘 2」。`firstStrike`、`firstCountdown` 也可以在合戰裡覆寫：`{ "id": "zhouYu", "firstStrike": "火計" }`、`{ "id": "luBu", "firstCountdown": 3 }`。

**技能的 `when`**（輪到攻擊時，第一個符合的技能取代普攻）：`every`（第 N、2N…次攻擊）、`hpBelow`（HP 低於比例，只用一次）、`first`（第一次攻擊，只用一次）、`chance`（機率 0～1）。

## 4. 站位（自動）

依星數自動排前後排與左右位置（`logic/formation.ts`，有測試）。「主將」＝最高星數：有 5★ 以上時只算 5★ 以上，否則 4★，都低於 4★ 時沒有主將。

| 敵人                    | 排法（由左到右）                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------- |
| 5 個以下低星（低於 4★） | 1 人：前；2 人：前前；3 人：後前後；4 人：後前前後；5 人：後前後前後               |
| 只有主將（例：2 個 4★） | 前前（並排）                                                                       |
| 1 個 4★＋2 個低星       | 前〔後〕前                                                                         |
| 2 個 4★＋2 個低星       | 前〔後後〕前                                                                       |
| 1 個 5★ 以上            | 〔前〕                                                                             |
| 1 個 5★＋2 個低於 5★    | 前〔後〕前（4★ 也算低星）                                                          |
| 其他有主將的組合        | 主將並排在中間、站後排；其他人分到兩側、都站前排（例：教學合戰 3＝前前〔後〕前前） |

有主將時低星一律站前排：主將比較大，低星站前面才不會被整個蓋住。

**大小**（相對 1★）：1★、2★ 1.0（縮放 0.30），3★ 1.15，4★ 1.5，5★ 1.75，6★ 以上 2.0；**6★ 以上**另外再放大到立繪看得到的部分（不含透明留白）＝畫面寬 640（兩者取大）。比例在 `formation.ts` 的 `BASE_SCALE`、`STAR_RATIOS`。

**上下**：立繪（含頭上的「殘 N」）**不會蓋到 Menu 按鈕**。太高時整排一起往下移，最低到我方頭像上方（HP 條不蓋到頭像）；還放不下才把那個敵人縮小。範圍是依畫面上 Menu 與頭像的實際位置量的（`units.ts` 的 `verticalLimits`），換手機尺寸、改元件位置都會跟著變。

**左右間距**（自動）：

- 先讓相鄰兩人看得到的部分邊緣相接，再分配畫面寬（640，兩邊各留 8）。
- 空間有剩：平均分給每個間隔（每個最多再拉開 60），整排撐開，不會看起來空空的。
- 空間不夠：可以重疊的兩人平均靠近（低星在前排蓋在高星前面），高星（4★ 以上）之間保持**不重疊**；例外：5★ 以上配 4★ 可以重疊（5★ 以上幾乎占滿畫面）。還是不夠就把這些高星縮小到放得下（寧可小一點也不互相蓋住）。
- 整排以看得到的左右兩端置中；JSON 裡低星敵人的順序決定誰在左側、誰在右側。
- 立繪寬度是載入合戰時從圖量出來的，新增敵人不用另外填。
- 點敵人鎖定目標時，依點到的像素判斷是誰（立繪圖透明的部分不算），疊在一起時點到誰就是誰。

## 5. 我方部隊（`data/parties.json`）

```json
"tutorial": [
  { "general": "starter", "attack": 42, "recovery": 11, "hp": 40 },
  { "faction": "han", "portrait": "武將圖鑑語音/4.漢/Others3/S&M/ch_40200040_s", "attack": 87, "recovery": 11, "hp": 33 }
]
```

`general: "starter"`＝玩家選的初始武將（勢力、頭像跟著換）；其餘寫 `faction`、`portrait`。兵種依頭像檔名自動判斷，也可以寫 `troop`。

## 6. 教學（`tutorial`）

`guidedMove`（照指定路徑轉珠）之後一樣會跑敵人回合，攻擊時機全由敵人的 `interval`／`firstCountdown`／`firstStrike` 決定，不需要在步驟裡另外安排。`script` 的步驟見 `docs/架構.md` 的「教學（JSON 步驟）」與 `TutorialMask.tsx` 的 `runTutorialScript`；教學中的合戰切換、勝利由步驟控制，勝利條件提示仍會依合戰的 `victory` 顯示。
