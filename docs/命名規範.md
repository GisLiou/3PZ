# 命名規範

目標：看到名字就知道「是什麼、單位是什麼」，不必回頭查縮寫。程式識別字用完整英文，註解與文件用繁體中文。

## 1. 規則

| 對象 | 規則 | 例 |
|---|---|---|
| 資料夾 | lowerCamelCase，名詞，表示一個功能或子部分 | `voicePack/`、`boardView/`、`starterSelection/` |
| React 元件檔 | PascalCase，與元件同名 | `TitleScene.tsx`、`SpriteButton.tsx` |
| 類別檔 | PascalCase，與類別同名 | `BoardView.ts`、`BattleScreen.ts` |
| 其他 .ts | lowerCamelCase | `saveStore.ts`、`battleTiming.ts` |
| 場景元件 | 以 `Scene` 結尾 | `PlayerNameScene`、`StarterSelectScene` |
| 單例服務 | 以 `Service`／`Store`／`Router` 結尾，小寫開頭的實例 | `audioService`、`saveStore`、`sceneRouter` |
| 常數表 | UPPER_SNAKE_CASE | `BATTLE_ASSETS`、`STARTER_GENERALS` |
| 時間常數 | 毫秒，名稱以 `Ms` 結尾；集中在 `xxxTiming.ts` | `matchTiming.swapMoveMs` |
| 布林 | `is`／`has`／`can` 開頭，或明確的狀態詞 | `isLocked`、`cannotDie` |
| 函式 | 動詞開頭；演出用 `play`、建立 DOM 用 `create`、畫到元素上用 `paint` | `playVictory()`、`createDimOverlay()`、`paintPieceSprite()` |
| 縮寫 | 不用單字母或自創縮寫；只保留業界通用的（`id`、`url`、`hp`、`bgm`、`ui`、`css`） | 寫 `openingTiming`，不寫 `T` |
| CSS class | kebab-case，前綴表示所屬畫面；狀態用 `is-` | `.battle-board`、`.piece.is-held` |
| CSS 變數 | kebab-case | `--design-unit`、`--fit-height` |
| 本機儲存 key | 一律用 `storageKey('名稱')` 產生，前綴 `3PZ.`（舊前綴 `threeKingdomsPuzzleWars.`、`sanpazu.` 啟動時自動搬移） | `3PZ.save.<帳號 id>` |
| 資料表檔名 | 對應原版素材檔名的保留原名（不改） | `data/atlas/puzzlelayout.json`、`data/font/BFBattleNum.json` |

保留不改的：場景 id（`tutorialBattle` 等，網址 `#scene=` 會用到）、原版素材路徑與檔名、錄影步驟名稱（`b1m1`＝教學戰鬥 1 第 1 次移動）。

## 2. 用語對照

| 中文 | 程式用語 | 說明 |
|---|---|---|
| 設計單位 | design unit（`designUnit()`） | 640 寬的座標系 |
| 小兵珠子 | piece | 盤面上的小兵；種類 `PieceKind` |
| 勢力 | faction | `wei` 魏、`wu` 吳、`shu` 蜀、`han` 漢、`qun` 群（漢語拼音）；桃子 `peach` 不是勢力 |
| 成陣（一組） | match group | 一組＝一連擊 |
| 往上補位 | refill upward | 本作小兵由下往上補 |
| 盤面記法 | board notation | `'PGVSGVS/…'`，字母 B 魏、R 吳、G 蜀、V 漢、S 群、P 桃 |
| 部隊成員／武將 | party member | 我方頭像 |
| 頭上小兵 | token | 武將頭像上方的小兵 |
| 衝鋒小兵 | troop | 攻擊時跑向敵人的大隻小兵 |
| 魂 | soul | 消除後飛到武將頭上的粉紅光 |
| 殘 N | countdown | 敵人攻擊倒數 |
| 軍略 | leader skill | 大將技能 |
| 合戰 | wave | 一場戰鬥中的第幾波敵人 |
| 玲玲 | navigator | 教學嚮導 |
| 主角三選一 | starter general | 孫權、劉備、曹操 |
