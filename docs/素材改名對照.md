# 遊戲素材改名對照

2026-10-30 將 `遊戲素材/` 內簡體中文的資料夾名、檔名轉為台灣繁體（OpenCC s2tw）。檔案內容未改動。

規則：
- 只轉換簡體字，不改用詞（例：`新建文件夹` → `新建文件夾`，不是「新增資料夾」）。
- 原版日文檔名不轉換：`ch_` 開頭的立繪／語音檔、`CV` 開頭的聲優資料夾、含假名的名稱（日文漢字如 権、関 原樣保留）。
- 手動修正：`台词` → `台詞`（不用「臺」）、`凌统` → `凌統`、`彻里吉&越吉` → `徹里吉&越吉`。
- 轉換後要重新執行 `npm run assets`；舊的轉檔結果（`game/public/` 內舊路徑）不會自動刪除。
