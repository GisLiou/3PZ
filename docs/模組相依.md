# 模組與相依關係

## 1. 相依圖

遊戲功能分成三大類（`modules/`），依玩家經過的順序：**starter**（啟動，每次開遊戲）→ **begin**（開始遊戲，每個帳號一次）→ **battle**（戰鬥）。
箭頭表示「使用」。`core` 不依賴任何遊戲模組；三大類之間只有一個例外：`starter` → `begin`（讀取中恢復帳號、檢查語音包；標題畫面判斷下一步），而且只用 `begin/index.ts` 的公開 API。`begin` 與 `battle` 互不 import，共用的初始武將資料放在 `data/generals/`。

```mermaid

  main[main.tsx] --> App[app/App]
  main --> Back[core/backButton]
  App --> Stage[core/stage]
  App --> Router[core/sceneRouter]
  App --> Registry[app/sceneRegistry 場景登記表]
  Registry --> Starter[modules/starter 啟動]
  Registry --> Begin[modules/begin 開始遊戲]
  Registry --> Battle[modules/battle 戰鬥]
  Starter --> Begin

  Battle --> Core

  Begin --> Ui
  Battle --> Ui
  Begin --> Data[data 資料表]
  Battle --> Data

```

## 3. 主要流程

### 3.1 啟動

```mermaid
sequenceDiagram
  participant M as main.tsx
  participant B as starter/BootScene
  participant K as saveStore（storageKey）
  participant A as assetLoader
  participant Acc as accountService
  participant R as sceneRouter
  M->>R: installBackButtonHandling()
  M->>B: 掛載（根場景 = boot）
  B->>K: migrateLegacyStorageKeys()（舊版 key 搬到新 key）
  B->>A: loadAssetManifest()
  B->>Acc: restoreSession()（有登入過就載入該帳號存檔）
  B->>A: preloadAssets(開場素材)
  B->>R: replace('notice')
```

### 3.2 開場（復刻 亞修實況 0～61 秒）

starter：`boot`（讀取中）→ `notice` →（2 秒或點擊）→ `title` →（點擊）
→ begin：未登入 `account` ／ 未取名 `name` → 未詢問語音 `voice` → `starter`（選擇初始武將）
→ battle：`story`（故事＋開門）→ `battle`（`stage: tutorial1`）→ `tutorialReward`（下一步）

場景 id `starter` 是「選擇初始武將」畫面（屬於 begin），和模組名稱 `starter`（啟動）不同，網址 `#scene=` 會用到所以保留不改。

### 3.3 返回

任何返回來源 → `sceneRouter.back()` → 目前場景若有 `onBack` 且回傳 `false` 則由場景自行處理（例：關閉對話框）→ 否則 pop 子場景 → 已在根場景時呼叫 `onExitRequest`：App 顯示「確定要離開遊戲嗎？」，再按一次返回＝取消；按「離開」時原生 App 關閉，網頁版回到進入遊戲前的頁面（沒有上一頁時提示自行關閉分頁）。

### 3.4 語音

建置時 `_開發工具_不需修改/素材轉檔/build-assets.mjs` 產生 `voice/voice-index.json` → 使用者在詢問畫面或系統設置按「下載」→ 逐檔存入 Cache Storage → `audioService.playVoice(id)` 從快取播放；未下載則略過。

### 3.5 一回合戰鬥（`BattleScreen.playTurn`）

`BoardView.resolveMatches()`（消除 → 魂 → 數字 → 補位 → 連鎖）→ `BattleScreen.ts` 下半的 `playComboMultiplier`（連擊倍率）→ `playLeaderSkill`（軍略）→ `playPartyAttack`（小兵衝向敵人、命中、死亡）→ 回復 HP。敵人回合：`playEnemyTurn`。

## 4. 新增功能的方式

1. 先決定屬於 starter／begin／battle 哪一類，在該類底下建資料夾（戰鬥的新部分放進五個部分之一，新關卡放 `battle/stages/<關卡>/`）；畫面元件與邏輯分開（邏輯不碰 DOM，方便測試）。功能由多個子部分組成時，每個子部分一個子資料夾，並以 `index.ts` 匯出公開 API。
2. 在 `app/sceneRegistry.ts` 登記場景 id。
3. 需要的存檔欄位加在 `SaveData`，並在 `SAVE_VERSION` 升版時於 `core/saveStore.ts` 的 `saveMigrations` 補遷移函式。
4. 依 [`命名規範.md`](命名規範.md) 命名。
5. 更新本文件的相依表與流程圖。
