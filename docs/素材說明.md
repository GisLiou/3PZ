# 素材說明

| 資料夾 | 數量 | 內容 | 安裝包 |
|---|---|---|---|
| `BG/` | 109 png | 任務背景 questbg_*、區域圖 | 包含 |
| `BGM/` | 19 ogg | bg_00001～00018、collabo | 包含（轉 mp3，iOS 不支援 ogg） |

## 2. 轉檔（`game/tools/assets/build-assets.mjs`）

- png → webp（品質 92、透明度無損）：`public/assets/<原路徑>.webp`，`manifest.json` 記錄原尺寸。目前約 387 MB（全部素材，尚未剔除未使用的）。
- ogg → mp3：`public/bgm/`，約 36 MB。
- 語音 mp3 原樣複製：`public/voice/`，13059 檔、約 177 MB，加上 `voice-index.json`。
- 程式內以「原始相對路徑（不含副檔名）」當素材 id。
- BGM 需要 ffmpeg；沒有 ffmpeg 時只略過 BGM，圖片與語音照常轉檔，最後列為失敗。
- 單一檔案失敗不會中斷，結束時的總表列出每一步的「總數／轉檔／略過／失敗／過期」；有失敗時結束代碼為 1。
- 每個檔案的處理結果寫在 `game/build-assets.log`（不進 git），可搜尋「失敗」「過期」「轉檔」。
- 過期＝`public/` 裡已經沒有來源的舊檔（例如素材改名後的舊路徑）；`npm run assets -- --clean` 會刪除並清掉空資料夾。
- 只跑其中一步：`npm run assets -- --only=assets`（或 `bgm`、`voice`）。

## 3. 圖集

原版有些圖集**沒有座標檔（plist）**，以 `game/tools/assets/slice-atlas.py` 依透明度找出每個零件的外框，座標存在 `game/src/data/atlas/<素材檔名>.json`（不產生新像素，畫面上用 CSS 取圖集的一塊）。

| 圖集 | 零件數 | 用途 |
|---|---|---|
| `UI等/戰鬥效果/puzzle_image` | 110 | 小兵珠子（姿勢表 `src/data/pieces/piecePoses.json`） |
| `UI等/戰鬥效果/puzzlelayout` | 65 | 戰鬥版面零件（HP 條、寶箱、Menu 字、瞄準符號…） |
| `UI等/戰鬥效果/tutorialImg` | 8 | 教學路徑指引（白條、手、箭頭） |
| `UI等/戰鬥效果/effect_data` | 37 | 斬線、放射光、血花、魂球 |
| `UI等/戰鬥效果/attack<勢力><兵種>` | 各 4～6 | 衝向敵人的大隻小兵 |
| `UI等/界面/resources-iphonehd/ccbMenuPartsA～F` | 30～90 | 標題列底板、各種圖示；**大部分零件用途尚未對照** |

- 有些零件在圖集中被**旋轉 90°** 存放；切圖工具目前不會偵測，用到時在程式中以 `rotationDeg=-90` 轉回（每個用到的零件都要人工確認）。
